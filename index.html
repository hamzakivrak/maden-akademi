Sıfırdan Adım Adım GitHub, Gist, APK (Telefon/TV) ve EXE (PC) Kurulum Rehberi

Hiçbir programlama veya paketleme bilmenize gerek kalmadan, bu sistemi bir kez kurup ömür boyu otomatik güncellenir şekilde nasıl kullanacağınız aşağıda adım adım anlatılmıştır:

1. Adım: GitHub Deposu (Repository) Açma ve Yükleme
  1. github.com adresine girip ücretsiz hesabınızı açın ve sağ üstteki "+" ➔ "New repository" butonuna tıklayın.
  2. Repository name kısmına maden-akademi yazın, Public seçin ve Create repository'ye basın.
  3. Size verdiğim maden_akademi_github_paketi.zip dosyasını klasöre çıkarın ve içindeki dosyaları (özellikle index.html) GitHub ekranındaki "uploading an existing file" linkine tıklayarak sürükleyip bırakın ve Commit changes'e basın.
  4. Üst menüden Settings ➔ Pages sekmesine girin, Branch kısmını main seçip Save'e basın. 1 dakika içinde https://kullaniciadiniz.github.io/maden-akademi/ adresiniz canlıya geçer!
2. Adım: Ücretsiz GitHub Gist (Cihazlar Arası Key & Veri Eşitleme)
  1. GitHub'da sağ üstten profil fotoğrafınıza tıklayıp Settings ➔ Developer settings (en altta) ➔ Personal access tokens ➔ Tokens (classic) bölümüne girin.
  2. Generate new token (classic) seçin, Note kısmına MadenGist yazın, Expiration kısmını No expiration yapın ve kutucuklardan sadece gist kutucuğunu işaretleyip en alttan Generate token'a basın.
  3. Size verilen ghp_... ile başlayan kodu kopyalayıp bu uygulamanın Ayarlar & Key sekmesindeki Gist kutusuna yapıştırın ve "Buluta Gönder"e basın.
  4. Uygulama size bir Gist ID verecek. Telefon ve TV'de sadece bu bilgileri girip "Buluttan Çek" dediğinizde tüm Gemini/Groq anahtarlarınız anında gelir!
3. Adım: Telefon ve Android TV İçin APK Yapma (Tek Seferlik)
  1. Yöntem A (En Pratik - PWABuilder): pwabuilder.com adresine girip GitHub Pages linkinizi (https://kullaniciadiniz.github.io/maden-akademi/) yapıştırın ve Package for stores ➔ Android ➔ Download APK deyin.
  2. Yöntem B (GitHub Otomatik Üretim): Size verdiğim ZIP paketinin içinde hazır .github/workflows/build.yml dosyası var. GitHub'da Actions sekmesine tıkladığınızda GitHub bulutu sizin yerinize otomatik .apk ve .exe üretir!
  3. Otomatik Güncelleme Sırrı: APK ve EXE doğrudan sizin GitHub Pages adresinizi okuduğu için, ileride GitHub'daki index.html dosyasını güncellediğiniz anda telefon, TV ve PC'deki uygulamanız yeniden APK/EXE kurmaya gerek kalmadan saniyesinde güncellenir!
4. Adım: Bilgisayar (PC) İçin EXE Yapma
  1. Bilgisayarınızda hiçbir ek kurulum yapmadan, Chrome veya Edge ile GitHub Pages adresinizi açıp adres çubuğunun sağındaki "Uygulamayı Yükle (Install App)" ikonuna basarsanız masaüstünüze bağımsız `.exe` kısayolu olarak iner.
  2. Tam bağımsız MadenAkademiSetup.exe dosyası isterseniz, ZIP paketindeki electron-main.js ve GitHub Actions iş akışı sayesinde GitHub üzerinden tek tıkla .exe olarak indirebilirsiniz.
